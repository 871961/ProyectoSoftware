📋 NOTAS IMPORTANTES
=======================================================================

1. Todas las contraseñas están hasheadas con bcrypt en la base de datos
2. Los médicos generales SOLO ven sus pacientes asignados
3. Los médicos especialistas pueden ver todos los pacientes
4. Los pacientes solo acceden a su propio perfil
5. El administrador puede gestionar médicos y ver estadísticas

6. Para cambiar contraseñas:
   - Genera el hash con: php -r "echo password_hash('nueva_contraseña', PASSWORD_BCRYPT);"
   - Actualiza en la BD: UPDATE medicos SET contrasena_hash = 'nuevo_hash' WHERE email = 'email@clinica.com';

✅ VERIFICAR ACCESO
=======================================================================

Si no puedes iniciar sesión:

1. Verifica que la base de datos esté actualizada:
   psql -U postgres -d medhistory -c "SELECT email, contrasena_hash FROM medicos LIMIT 1;"

2. Verifica que el hash coincida:
   - Todos los médicos deben tener el hash: $2y$10$Joc080WMq2rrLGPLGwUQ2O7wKUgjmmgTavdOT/xYLD44c43mXWvta
   - Todos los pacientes deben tener el hash: $2y$10$1ra02Z0q35KcTdfr.5HF1OCWBTgj.vrth1IsghM0TiB2f5V59oJVO

3. Si los hashes son diferentes, ejecuta:
   psql -U postgres -d medhistory -f database/reinstalar_completo.sql
   psql -U postgres -d medhistory -f database/datos_prueba.sql
